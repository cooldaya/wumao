# 🔸 五猫游戏 - 菱形棋盘策略游戏

## 🎮 游戏简介

五猫游戏是一款基于菱形棋盘的策略对战游戏，融合了传统棋类游戏的移动规则和独特的"策反"机制。玩家需要运用策略移动棋子，通过夹击和包围来策反对方的棋子，最终获得胜利。

## 🎯 核心特色

- **独特的菱形棋盘设计**：7x5的菱形网格布局，提供丰富的战术空间
- **创新的策反机制**：通过夹击和包围来转化对方棋子
- **连锁反应系统**：一次移动可能引发多次策反，增加游戏变数
- **智能保护机制**：对弱势方提供特殊保护，保持游戏平衡
- **精美的视觉效果**：使用Konva.js实现流畅的动画和交互

## 🕹️ 游戏规则

### 基本规则
1. **玩家轮流**：🔴 红方和 🟢 绿方轮流移动棋子
2. **移动方式**：棋子只能沿着棋盘上的直线移动，可以走多格
3. **胜利条件**：
   - 策反对方所有棋子，使对方无子可用
   - 或将对方最后一枚棋子逼至菱形格顶部且无路可走

### 策反机制（核心玩法）
策反作用于同一条线上的相邻位置：

- **夹击策反**：当我方棋子移动后，敌方棋子被夹在我方两枚棋子之间的同一条线上时，该敌方棋子被策反
- **包围策反**：当我方棋子移动后，敌方两枚棋子分别位于我方棋子两边的同一条线上时，这两枚敌方棋子被策反
- **连锁反应**：策反可以产生连锁反应，一次移动可能引发多次策反

### 特殊保护机制
- 对方剩最后一颗棋子时，不可以被夹死，只能将其围堵至棋盘顶部菱形网格后无路可逃才能获胜
- 对方剩两颗棋子时，不可以被单独夹死，但可以同时被夹死
- 注意：特殊保护机制不影响连锁反应的发生

## 🛠️ 技术实现

### 技术栈
- **前端框架**：纯HTML5 + CSS3 + JavaScript
- **图形渲染**：Konva.js (2D图形库)
- **构建工具**：无需构建，直接运行
- **浏览器支持**：现代浏览器（Chrome、Firefox、Safari、Edge）

### 核心数据结构
```javascript
// 棋盘配置
const gameConfig = {
  board: { width: 600, height: 700, gridSize: 100 },
  piece: {
```

### 核心功能模块

1. **棋盘初始化** (`initializeBoard`)
   - 创建7x5菱形网格
   - 设置红绿双方初始棋子位置
   - 初始化Konva.js图层

2. **棋子移动逻辑** (`getCanPlacePoints`)
   - 基于连接关系搜索可移动位置
   - 实现阻挡检测和路径计算
   - 支持多格直线移动

3. **策反检测系统** (待实现)
   - 夹击检测算法
   - 包围检测算法
   - 连锁反应处理

4. **可视化交互** (`showCanPlacePoints`)
   - 高亮显示可移动位置
   - 棋子选中效果
   - 移动动画

## 🚀 快速开始

### 环境要求
- 现代浏览器（Chrome、Firefox、Safari、Edge）
- 无需服务器，可直接本地运行

### 运行步骤
1. 克隆或下载项目文件
2. 在项目目录中打开 `index.html`
3. 开始游戏！

```bash
# 项目结构
五猫游戏/
├── index.html          # 主页面
├── main.js            # 游戏逻辑
├── lib/
│   └── konva.min.js   # Konva.js库
└── README.md          # 项目文档
```

## 🎮 游戏操作

1. **选择棋子**：点击己方棋子，会高亮显示可移动位置
2. **移动棋子**：点击高亮的空位来移动棋子
3. **策反对手**：移动后自动检测并执行策反
4. **撤销操作**：点击"撤销"按钮可回退上一步
5. **游戏提示**：点击"提示"按钮获取移动建议
